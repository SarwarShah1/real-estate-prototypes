# real-estate-prototypes
## Developer sites (generated)
`dhilal/` and `sarh/` are generated by a small Node static-site generator in `_build/` (no dependencies). Every page is a real URL in English and Arabic (`/ar/`), with SEO tags, hreflang, JSON-LD, sitemap.xml and robots.txt.
- Edit content in `_build/dhilal-data.mjs` / `_build/sarh-data.mjs`, pages in `_build/*-pages.mjs`, styles in `_build/*.css`.
- Rebuild: `node _build/dhilal-pages.mjs && node _build/sarh-pages.mjs`, then commit the output folders.
